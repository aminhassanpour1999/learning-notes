# Basic Debugging

> Status: Planned. This file is an outline only. We will study and expand it together when we reach this topic.

## What you will learn

- Reading tracebacks from the bottom upward
- Syntax, runtime, and logic errors
- Using print() to inspect values
- Reproducing a bug with a minimal example
- Forming and testing hypotheses
- Writing useful error reports

## Learning goal

Diagnose simple errors systematically rather than guessing.
