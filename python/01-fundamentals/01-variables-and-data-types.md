# Variables and Data Types

> **Status:** Syllabus outline. We will expand this lesson into teaching notes, a coding lab, exercises, and a small project when we study it.

## Learning objectives

By the end of this lesson, you should be able to:

- Explain the relationship between a value, an object, a name, and assignment at a beginner-friendly level.
- Choose meaningful variable names that follow Python conventions.
- Recognize common built-in types: `int`, `float`, `str`, `bool`, and `NoneType`.
- Inspect a value's type with `type()` and distinguish a value from its textual representation.
- Predict the effect of reassignment without treating a variable as a permanent box.

## Sections

1. **Values, objects, and names** — what a variable name refers to.
2. **Assignment and reassignment** — `=` binds a name; it does not mean mathematical equality.
3. **Naming rules and conventions** — valid identifiers, readable names, keywords, and common mistakes.
4. **Core built-in types** — integers, floating-point numbers, strings, booleans, and `None`.
5. **Inspecting values** — using `type()` and reading simple type information.
6. **Equality is not identity** — a gentle introduction to `==` versus `is`; detailed boolean logic comes later.
7. **Common beginner mistakes** — misspelled names, accidental reassignment, misleading names, and type assumptions.

## Coding lab

Create a small measurement summary using clearly named variables. Inspect the values and types, then reassign one variable and predict what changes.

## Exercises

- Identify the values, names, and types in short snippets.
- Repair invalid or misleading variable names.
- Predict the result of a sequence of assignments.
- Explain why `"25"` and `25` are different kinds of values.

## Knowledge check

Explain, without copying a definition, what assignment does and how you would check a value's type.
