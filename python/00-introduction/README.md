## How to study this section

- Read to understand, then close the notes and explain the idea in your own words.
- Run every example and predict its output before execution.
- Complete small exercises without copying solutions.
- Use the official documentation as a reference, not as a requirement to read every page linearly.
- Keep historical and implementation details concise until they become relevant to real work.
