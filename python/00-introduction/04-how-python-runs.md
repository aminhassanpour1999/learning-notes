# How Python Runs

## Purpose

Develop an accurate beginner-friendly mental model of how Python source code becomes program behavior.

## Topics

- Source code, execution, and runtime
- The role of the Python interpreter
- Compilation and interpretation: what the terms mean
- A high-level view of CPython's source-to-bytecode-to-execution process
- What bytecode and the Python virtual machine are
- Python implementations: CPython and a brief note on PyPy
- Why “Python is interpreted” is useful shorthand but not the whole story
- What beginners need to know now versus what can wait

## Learning outcomes

You should be able to describe the broad execution path without confusing the Python language with one particular implementation.
