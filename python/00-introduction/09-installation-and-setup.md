# Installation and Development Setup

## Purpose

Prepare a reliable Python environment and understand which interpreter is running your code.

## Topics

- Check whether Python is already installed
- Choose a suitable supported Python 3 version
- Install or update Python using an appropriate method for the operating system
- Understand the difference between Python, an interpreter, and an editor
- Verify the installation from a terminal
- Select the correct interpreter in VS Code
- Recognize common PATH and interpreter-selection problems
- Learn why project environments matter; detailed package management belongs in a later note

## Verification checklist

- [ ] A Python 3 interpreter runs successfully.
- [ ] The Python version can be checked from the terminal.
- [ ] VS Code can select the intended interpreter.
- [ ] A simple script can be run from the chosen environment.

## Official references

- [Python setup and usage](https://docs.python.org/3/using/index.html)
- [Python downloads](https://www.python.org/downloads/)
