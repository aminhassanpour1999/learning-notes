# Running Python Code

## Purpose

Learn the everyday workflow for running code, using a terminal, and working effectively in an editor.

## Topics

- Interactive interpreter (REPL) versus script files
- What a terminal and shell do
- Basic navigation: current directory, listing files, and changing directories
- Running a Python script from the terminal
- Using VS Code to open a folder, select an interpreter, run a file, and inspect output
- Relative paths and the current working directory
- Common execution problems and a basic debugging checklist

## Practice

- Run a one-line command in the interactive interpreter.
- Save the same idea in a `.py` file and run it.
- Run the file from the terminal and from VS Code.
- Intentionally run a command from the wrong directory and diagnose the result.

## Learning outcomes

You should be able to choose between interactive work and a script, run a file reliably, and identify whether a problem comes from code, the interpreter, or the working directory.

> Detailed debugging, testing, and virtual-environment workflows belong in dedicated later sections.
