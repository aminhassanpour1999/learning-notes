# Python Documentation

## Purpose

Learn to use official documentation as a normal part of programming, not only when you are stuck.

## Main resources

- [The Python Tutorial](https://docs.python.org/3/tutorial/): a guided introduction to the language
- [The Language Reference](https://docs.python.org/3/reference/): formal details of Python syntax and semantics
- [The Standard Library](https://docs.python.org/3/library/): modules included with Python
- [The Glossary](https://docs.python.org/3/glossary.html): precise definitions of Python terms
- [Python Packaging User Guide](https://packaging.python.org/): installing packages and managing project environments
- [Python Package Index (PyPI)](https://pypi.org/): discovering third-party packages

## How to read documentation

1. Identify the exact question you are trying to answer.
2. Check the Python version and whether the page describes the language or a library.
3. Read the smallest relevant section and inspect its examples.
4. Run a minimal example yourself.
5. Record the concept and a useful example, not a copy of the entire page.

## Learning outcomes

You should know which official reference to consult for a language feature, a standard-library module, or package-management guidance.

> The official tutorial assumes some general programming knowledge. Use it alongside hands-on exercises and beginner-friendly explanations where necessary.
