# Programming Fundamentals

## Purpose

Understand the basic ideas behind programming before focusing on Python syntax.

## Topics

- Programs, instructions, and algorithms
- Input, processing, and output
- Data and operations
- Expressions and statements (introductory overview)
- Variables as names bound to values (preview only)
- Sequence, selection, and repetition (conceptual preview)
- Decomposing a problem into smaller steps
- Translating a plain-language task into an algorithm

## Practice

For everyday tasks, write down the inputs, steps, and expected outputs before attempting to code them.

## Learning outcomes

You should be able to describe an algorithm in plain language, identify a problem's inputs and outputs, and break a task into small, testable steps.

> Detailed syntax and language features belong in the later fundamentals and control-flow sections.
