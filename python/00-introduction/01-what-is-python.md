# What Is Python?

## Purpose

Build a clear mental model of Python, why it exists, what makes it useful, and where its trade-offs matter.

## Topics

- What a programming language is
- Python's design philosophy and readability
- A concise history: origins, Python 2 to Python 3, and ongoing development
- Major strengths: readability, ecosystem, portability, and developer productivity
- Trade-offs: runtime performance, deployment considerations, and cases where another tool may fit better
- What it means to learn a language versus learn to program

## Learning outcomes

After this note, you should be able to explain Python in your own words, name its major strengths and limitations, and distinguish facts about the language from hype.
