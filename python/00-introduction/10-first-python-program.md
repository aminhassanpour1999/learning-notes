# Your First Python Program

## Purpose

Write, run, inspect, and modify a small Python program.

## Topics

- Create a `.py` file
- Write a minimal program using `print()`
- Run it from the terminal and from the editor
- Understand the difference between source code and output
- Change the program and run it again
- Read simple error messages without panicking
- Follow basic file-naming and project-organization habits

## Example

```python
print("Hello, world!")
```

Expected output:

```text
Hello, world!
```

## Practice

1. Change the message.
2. Print two separate lines.
3. Print a short sentence about something you want to build with Python.
4. Intentionally introduce a small syntax error, run the program, and inspect the message. Then fix it.

## Learning outcomes

You should be able to save a Python file, execute it, compare actual output with expected output, and make a small change independently.
