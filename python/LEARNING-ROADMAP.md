# Python Learning Roadmap

This roadmap describes the order in which to build skills. It is intentionally separate from the introductory notes because it guides the entire Python curriculum.

## Stage 1 — Orientation and setup

- Understand what Python is and how programs run.
- Set up an interpreter, editor, and terminal workflow.
- Write and run a first program.
- Learn to consult the official documentation.

## Stage 2 — Core programming

- Variables, values, basic types, and operators
- Strings, numbers, and user input
- Conditions and loops
- Lists, tuples, dictionaries, and sets
- Functions, parameters, return values, and scope
- Exceptions and file handling

## Stage 3 — Write maintainable programs

- Modules, imports, and packages
- Object-oriented programming when it helps model a problem
- Debugging and reading tracebacks
- Testing and assertions
- Code style, naming, and refactoring
- Git and project organization

## Stage 4 — Work with real projects

- Build command-line tools and small automation scripts
- Read and write structured data
- Use virtual environments and install dependencies safely
- Document projects and write useful READMEs
- Complete projects without following a tutorial line by line

## Stage 5 — Specialize for engineering and research

- NumPy and numerical computing
- Plotting and data analysis
- SciPy and scientific workflows
- Signals and systems applications
- Communications and simulation
- Machine learning foundations

## Definition of progress

Move forward when you can explain the main idea, solve a few new problems without copying, debug a basic mistake, and use documentation to answer a question. Do not wait for perfect mastery, but do not mistake reading for practice.
