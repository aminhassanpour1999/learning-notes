# Python Learning Path

This folder is a structured learning system, not a copy of any single book. The official Python documentation is a core reference, supported by deliberate practice, small projects, and other reliable resources.

## Learning principles

1. Understand concepts before memorizing syntax.
2. Write and run code every study session.
3. Predict output before running examples.
4. Solve exercises independently before checking solutions.
5. Revisit topics through spaced review and small projects.
6. Keep concise, useful notes; avoid documenting every trivial detail.
7. Learn to use official documentation as a normal part of programming.

## How to use the notes

- Treat each note as a reference, not a substitute for coding.
- Mark topics as planned, in progress, or reviewed where useful.
- Add examples only when they clarify a concept.
- Link related notes instead of repeating explanations.
- Keep exercises separate from worked solutions where practical.

## Long-term direction

After building strong Python fundamentals, extend the path into mathematics, scientific computing, signals and systems, communications, machine learning, and research workflows.
